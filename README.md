# PowerCheat

**PowerCheat** — асинхронный Telegram-бот для автоматизации рутинных действий в браузерной игре PokePower.

Проект позволяет управлять игровым ботом непосредственно из Telegram: задавать цели, выбирать параметры ловли и фарма, запускать автоматическое исследование мира и контролировать выполнение задач без постоянного участия пользователя.

## Возможности

* 🤖 Управление игровым ботом через Telegram
* 🌐 Автоматизация браузера с помощью Playwright
* ⚔️ Автоматические сражения с покемонами
* 🎯 Фарм выбранных покемонов и предметов
* 📥 Автоматическая ловля покемонов
* ⚥ Фильтрация покемонов по полу
* ✨ Поиск и ловля шайни-покемонов
* 🎯 Поддержка количества целей — например, `Пикачу:10`
* 🏥 Автоматическое лечение команды в ближайшем Покецентре
* 🗺️ Поиск маршрута до нужной локации
* 🧭 Использование карты игрового мира для построения маршрутов
* 🎒 Выбор покебола для ловли
* ⚡ Автоматический выбор наиболее эффективной атаки с учётом типов покемона
* 🔄 Автоматическое возвращение к фарму после лечения
* 🛑 Возможность остановить выполнение бота из Telegram
* 👤 Хранение настроек пользователей в SQLite
* 💬 Система обратной связи с администратором
* 💳 Система подписок и оплаты
* 🌐 Поддержка прокси для браузерной сессии

## Как это работает

Архитектура проекта разделена на две основные части:

```text
Telegram
   │
   ▼
┌─────────────────────┐
│     Telegram Bot    │
│       aiogram       │
└──────────┬──────────┘
           │
           │ настройки / команда запуска
           ▼
┌─────────────────────┐
│    Browser Bot      │
│      Playwright     │
└──────────┬──────────┘
           │
           ▼
┌─────────────────────┐
│      PokePower      │
│   браузерная игра   │
└──────────┬──────────┘
           │
           ├── Сражения
           ├── Ловля
           ├── Передвижение
           ├── Лечение
           └── Сбор предметов
```

Пользователь задаёт необходимые параметры через Telegram. После запуска бот открывает браузер, авторизуется в игре и начинает выполнять поставленную задачу.

Во время работы бот анализирует состояние боя, здоровье команды, доступные атаки, предметы и текущую локацию.

## Автоматическое перемещение

Для перемещения используется набор данных о карте игрового мира.

Каждая локация содержит информацию о доступных переходах:

```text
Паллет:Академия тренеров:Дорога 1:Покецентр:Покемаркет
Дорога 1:Паллет:Дорога 2
Дорога 2:Дорога 1:Виридиан
```

На основе этих данных программа строит граф игрового мира и ищет кратчайший путь между текущей и необходимой локацией.

Это позволяет автоматически:

* находить нужную локацию;
* перемещаться к месту обитания определённого покемона;
* перемещаться к месту получения определённого предмета;
* возвращаться в Покецентр;
* продолжать выполнение задачи после лечения.

## Система целей

Цели задаются пользователем через настройки Telegram-бота.

Например:

```text
Пикачу
```

означает поиск и ловлю Пикачу, а

```text
Пикачу:10
```

— необходимость поймать 10 экземпляров.

Аналогичный механизм используется для фарма предметов.

Можно комбинировать несколько целей:

```text
Пикачу:10, Чармандер:5
```

Бот отслеживает оставшееся количество каждой цели и завершает выполнение после достижения необходимых значений.

## Автоматические сражения

Во время боя бот анализирует доступные атаки и тип противника.

Для выбора оптимальной атаки используется таблица эффективности типов:

```text
Огненный → Травяной = 2x
Водный   → Огненный  = 2x
Электр.  → Водный    = 2x
```

Таким образом, бот не просто выполняет одну заранее заданную атаку, а выбирает наиболее эффективный вариант в зависимости от типа противника.

## Ловля покемонов

Поддерживаются различные покеболы, включая:

* Покебол
* Гритбол
* Ультрабол
* Мастербол
* Генобол
* Шайнибол
* Дистанцбол
* Взломанный шайнибол

Для каждого покебола хранится соответствующий идентификатор элемента интерфейса игры.

Также предусмотрена отдельная логика выбора покебола в зависимости от настроек пользователя.

## Фильтрация по полу

При ловле можно указать необходимый пол покемона:

```text
мужской
женский
бесполый
```

Бот определяет пол встретившегося покемона и принимает решение о ловле на основании заданных пользователем параметров.

## Ловля шайни

Проект поддерживает отдельный режим поиска шайни-покемонов.

При включённом режиме бот отслеживает появление нужного покемона и использует специальные предметы для его ловли.

## Автоматическое лечение

Во время длительного фарма бот контролирует состояние команды.

При необходимости он:

1. прекращает текущую активность;
2. строит маршрут до Покецентра;
3. перемещается в Покецентр;
4. восстанавливает команду;
5. при необходимости выгружает пойманных покемонов;
6. возвращается обратно;
7. продолжает выполнение задачи.

Это позволяет использовать бота для длительного автономного фарма.

## Telegram-интерфейс

Telegram используется как основной интерфейс управления.

Основные разделы:

```text
🏠 Главное меню
├── 🕹 Запуск
├── 👤 Аккаунт
├── ⚙ Настройки
└── 🏳️ Помощь
```

### Аккаунт

Пользователь может сохранить:

* логин;
* пароль.

Пароль отображается в Telegram в замаскированном виде.

### Настройки

Доступны параметры:

* количество боёв;
* предметы для фарма;
* покемоны для ловли;
* пол покемона;
* используемый покебол;
* режим Shiny Hunt.

### Управление

Во время выполнения задачи бот позволяет остановить браузер и завершить выполнение.

## Установка

Клонировать репозиторий:

```bash
git clone https://github.com/<username>/PowerCheat.git
cd PowerCheat
```

Создать виртуальное окружение:

```bash
python -m venv venv
```

Активировать его:

### Windows

```bash
venv\Scripts\activate
```

### Linux / macOS

```bash
source venv/bin/activate
```

Установить зависимости:

```bash
pip install -r requirements.txt
```

Установить браузеры Playwright:

```bash
playwright install
```

Создать файл с конфигурацией и указать необходимые токены и параметры:

```text
data/tokens.env
```

После настройки запустить:

```bash
python main.py
```

## Конфигурация

Секретные данные не должны храниться непосредственно в исходном коде.

Рекомендуется использовать переменные окружения для:

* Telegram Bot Token;
* административного ID;
* API-ключей;
* данных платёжной системы;
* других приватных параметров.

> **Важно:** если `data/tokens.env` когда-либо был опубликован в Git-репозитории, токены необходимо считать скомпрометированными и заменить их.
